# 시차마루

[사이트 사용하기](https://sicha-maru.netlify.app/)

33개 도시의 현지 날짜·시각, 서머타임, 공통 근무시간을 비교하는 한국어 회의 계획 도구입니다. 입력을 전송하거나 저장하지 않는 정적 사이트입니다.

- 날짜별 UTC 오프셋, 시작·종료 날짜, 기준 날짜와의 차이
- 존재하지 않는 시각 거부, 반복 시각의 명시적 선택
- 도시별 근무 범위와 현지 주말을 고려한 실제 회의 전체 길이 검사
- 다음 24시간의 30분 간격 후보 중 공통 시간 최대 6개 제안
- 도시별 일정 복사, UTC 기반 ICS 파일 다운로드

`npm test`로 핵심 계산을 검증합니다. 로컬 실행: `python -m http.server 4174 --directory dist`. 빌드·패키지 설치 없이 `dist`를 정적 호스팅에 배포합니다.

입력은 2000~2099년, 비교 도시는 1~6개, 회의 길이는 15~180분입니다. 목록의 현대 시간대에서 가능한 -14~+14시간의 모든 분 단위 오프셋을 역검증해 중복/누락 현지 시각을 판별합니다. 브라우저 Intl의 IANA 데이터에 의존하므로 향후 시간대 정책 변경은 최신 브라우저에서 재확인해야 합니다. 공휴일·개인 일정·밤샘 근무는 반영하지 않습니다.

기준: [ECMA-402 Intl](https://tc39.es/ecma402/), [RFC 5545 iCalendar](https://www.rfc-editor.org/rfc/rfc5545). 캘린더 파일은 CRLF, UTF-8 75옥텟 줄 접기, 텍스트 이스케이프와 UTC 시작/종료를 사용합니다. 초대 발송 기능은 없습니다.
